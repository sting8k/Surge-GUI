# Story Backlog

This backlog captures candidate epics derived from the current product direction.
Do not create every possible story packet up front. Create story packets when the
work is selected or when a product decision needs a durable place to land.

## Candidate Epics

- E01 Backend Freshness
  - Description: verify and support the current Surge backend version.
  - Status: unsliced.
- E02 Core Download Manager
  - Description: complete expected controls, states, history, retry, and recovery.
  - Status: unsliced.
- E03 Queue And Control
  - Description: define predictable multi-download queue behavior.
  - Status: unsliced.
- E04 Professional Desktop UX
  - Description: polish desktop states, accessibility, platform behavior, docs.
  - Status: unsliced.
- E05 Validation Readiness
  - Description: add proof for backend, UI behavior, and platform packaging.
  - Status: unsliced.

## First Story Candidates

- Verify latest supported Surge backend compatibility.
- Define canonical download states and transitions.
- Define queue ordering and active download limit behavior.
- Add user-facing handling for backend offline or unsupported version states.
- Replace generated/template README content with product-specific docs where it
  still exists.
